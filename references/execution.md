# 计算与产物

先测一个小批次或短训练段的速度和内存，再估算全量成本。GPU 配额、并发数、镜像、联网方式和 CLI 参数以当前平台及安装版本为准；不要把历史数值当保证。查询官方工具的 `--help` 与平台说明后记录实际命令。

本地适合快速验证和小任务；需要 GPU、大内存或比赛挂载数据时使用已授权的 Kaggle 运行环境。开始前确认私有设置、所附比赛数据、模型和依赖。不能通过输出环境变量诊断认证问题。

多阶段流程可拆为产出模型或特征的任务和最终推理任务。每份中间产物的 manifest 包含运行 ID、代码与配置标识、训练单位范围、模型文件及其哈希、输出 schema 和依赖版本。消费端核对 manifest、训练范围与实际文件；缺模型时失败，不悄悄换成临时训练或另一个模型。

使用平台支持的版本化存储，记录实际 Notebook 和数据集版本。只在确认下载的是所需运行版本后登记结果，避免 latest 更新导致实验和产物错配。发布新版本前收齐旧版仍需的日志与输出。

长任务使用后台执行或平台作业，并保存日志位置。调度时记录待启动、运行、完成、失败、取消的实际状态；轮询要有间隔和截止时间。恢复会话时先查回执，不重复启动同一任务。

并行实验仅适用于彼此独立且总成本在预算内的任务。委派时给出目标、输入、产物协议、允许操作和成本上限；每个任务使用独立运行目录。主执行者验证结果并作晋级决定。

代码赛的可见测试只用于运行检查。估算隐藏规模下的启动、加载、单样本耗时、内存增长和写出成本，使用保守规模与余量。实际测量精度、批量、模型数量和增强的权衡；不能仅靠缩小模型而假定仍有同样效果。

用模拟的输入测试少量文件、不同顺序、大批量、缺失字段、离线加载和干净启动。合法的降级必须提前验证并留下日志；关键依赖缺失和评分逻辑错误应明确失败，不能用训练数据或空模板伪装成功。输出通过临时文件校验后原子替换，保留每阶段时间和实际预测数量。
