# 实验推进

先跑格式和指标检查，再建立低成本模型。表格任务可先用提升树；稀疏文本可先用线性模型；图像和音频可用允许的预训练表示；预测任务先与朴素时间基线比较；模拟任务先实现合法动作和可靠对战评估。选择与数据匹配的方案，不强制使用同一库。

基线需要保存样本外预测、各折表现、模型和有效输出。自己的验证器必须运行候选实际改变的阶段；缺失关键阶段的简化代理只能用于初筛。对训练来源不透明的公开权重，要明确它是否能支持干净的训练集验证。

每轮实验先追加 `experiments.jsonl` 事件，写出假设、父版本、比较对象、固定数据划分、接受标准、时间和费用上限。开始时间应早于读到结果的时间。事件格式为带 `id` 和 `event` 的 JSON 对象，可用 `workspace.py record` 追加。

从误差分析决定实验：改善最弱群体、修正标注处理、增加新信息、调整训练、引入不同模型或改进推理。先估算这个误差来源最多影响多少分；预期收益很小时，不要用昂贵训练验证微小变化。先测已有产物能回答的简单问题。

改变多个因素可以用于探索，但不能据此声称某一个因素有效。探索结果要用更窄的对照复核。失败应区分实现错误、无可检测收益和假设错误。

晋级至少需要：产物身份正确、验证覆盖充分、相同划分上的有效提升、预设实际收益达标、重要分组没有不可接受损害、预算与推理限制可满足。记录失败标准而不只写 PASS/BLOCK；无有效比较时结论是证据不足。工具的统计通过不能直接变成正式提交指令。

集成先从少量不同模型的简单平均开始。用合法的样本外预测比较单模型和集成，检查误差互补性及每个成员的边际作用。复杂堆叠的训练和评分也要隔离；用同一份 OOF 拟合权重再在其上报告提升仍有选择偏差。不能只因为预测相关性低就加入一个很差的模型。

每轮结束记录代码标识、配置、数据和 fold 标识、随机种子、模型及预测文件哈希、分数、耗时、成本和结论。先检查实际文件，再接受远程任务或子 agent 的报告。新证据不足时允许维持基线，不把不断改动当作不断优化。
