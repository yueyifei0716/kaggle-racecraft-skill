# 可信评估

验证设计应模拟部署到隐藏数据时会遇到的变化。先确定独立单位：一位病人、一段视频、一个地点或一个时间窗口里的多行数据，不能默认是多个独立样本。

## 划分和指标

保存稳定的样本 ID、单位、组别和 fold 映射。分类可做分层，重复实体须分组，预测未来须按时间划分；若隐藏集来自新医院或新地区，还要测量跨医院或跨地区的迁移。样本不足时公开不确定性，不为了凑折数制造独立性。

将官方评分实现为本地可运行的检查，用已知例子核对边界、方向、汇总和缺失值约定。AUC 等整体指标在完整样本外预测上计算，不能随意用各折平均代替。模拟赛要与多类对手在同一批种子上比较，并检查先后手；自我对战获胜不代表对整个赛场更强。

所有会学习数据的操作都属于训练流程，包括填补、缩放、特征筛选、目标编码、校准和集成权重。它们不能提前看到本折验证标签。早停和阈值选择用训练侧的内层划分，再在外层评估。伪标签的产生与过滤要记录训练范围，不能把验证标签变相传回模型。

检查重复样本、增强前后的归属、预训练权重是否接触了比赛标签。必要时做打乱标签、移除可疑特征或跨组测试；一次打乱测试正常不能证明没有泄漏。

## 开发数据也会被过拟合

即使每次预测是样本外的，反复查看同一组结果并选择方案，也会适应该组数据。记录尝试数量，限制大规模搜索，把搜索得到的优势在未参与选择的数据或新分组上复核。

数据量允许时预先封存一份独立保留集，保存 ID 清单和封存时间。开发期间不用于早停、选特征或挑参数。收尾时对预先确定的少量候选打开；若看完又继续调整，这份数据应标记为已参与开发，不能再声称是未触碰测试。保留集不足或分布不符时不要把它当绝对裁判。

## 怎样读一个提升

在完全对应的单位上比较新旧方案，观察总体、各组、各折与重要困难样本。对独立单位做成对重采样；如果独立性在更高层，就在更高层重采样，不能按行低估误差。时间依赖要用合适的区块方法。

`paired_check.py` 仅适用于已算出可比较的单位分数的初筛。完整晋级用 `analysis.py gate`，核验实际候选哈希、行级预测、单位/fold/组别对应、阶段覆盖及复现实验。对 AUC 等整体指标重新计算整体分数并按独立簇重采样，不能把行级误差或单位 AUC 均值冒充整体 AUC。区间不跨零仍不代表已解决所有多重比较或分布漂移。

公榜的用途取决于独立样本数、代表性和本地验证的可信度。少量分数不能可靠估计相关性；大量相似提交也不等于多个独立证据。矛盾时分别调查本地泄漏、指标偏差、产物不一致、公榜噪声和分布变化。不要凭一次公榜上升晋级，也不要无视持续、可解释的反向证据。
